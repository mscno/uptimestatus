# Report fonts

Embedded in the binary for PDF reports (Typst reads TrueType, not WOFF2). All
are under the SIL Open Font License 1.1; the licence texts are alongside.

| File | Source |
|---|---|
| `IBMPlexSans-Regular.ttf`, `IBMPlexSans-SemiBold.ttf` | IBM Plex Sans 3.005, `IBM/plex` `packages/plex-sans/fonts/complete/ttf` |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` | `static/starbase/fonts/jetbrains-mono.woff2` (the console's subset), converted with fontTools and instanced at weights 400 and 700 |
| `PixelifySans-SemiBold.ttf` | `static/starbase/fonts/pixelify-sans.woff2` (the pixel look's display face), converted with fontTools and instanced at weight 600 |
